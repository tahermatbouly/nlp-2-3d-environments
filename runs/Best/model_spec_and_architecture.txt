3. MODEL ARCHITECTURE
--------------------------------------------------------------------------------
- Total Trainable Parameters: 13,371,904 (~13.37 Million parameters)
- Graph Conditioning Encoder:
  * Architecture: 4-layer Graphormer (Graph Transformer)
  * Hidden Embedding Dimension (d_model): 256
  * Multi-Head Self-Attention Heads: 8 (head dimension 32)
  * Feedforward Intermediate Dimension: 1024 (GeLU activation)
  * Spatial & Relational Bias: Learned 2D relational attention bias matrix E in R^{N x N x d_head} encoding edge types between rooms (0=Unconnected, 1=Door/Connected, 2=Interior Wall, 3=Self).
- Generative Denoiser:
  * Architecture: 6-layer Diffusion Transformer (DiT) operating on continuous 2D coordinate tokens
  * Hidden Dimension (d_model): 256
  * Attention Heads: 8
  * Conditioning Injection: Adaptive Layer Normalization Zero (AdaLN-Zero) modulating scale and shift parameters for timestep t and pooled graph tokens.
- Output Representation & Coordinate Parameterization:
  * Output Tensor: Predicts clean continuous vertex coordinates x_0 in R^{B x N x V_max x 2}.
  * Maximum Rooms: N = 12.
  * Maximum Vertices per Room: V_max = 8.
  * Canonical Canvas Space: 256 x 256 pixels, normalized by scale factor S = 168.0 to [-1.0, 1.0].
  * Room Topology Constraint: Living room specifically regularized to V in {4, 6, 8} orthogonal corners; bedrooms, bathrooms, and utility rooms parameterized as 4-vertex bounding boxes.

4. CONDITIONING INPUT SPECIFICATION
--------------------------------------------------------------------------------
- Bubble Graph Input:
  * Node Features (Room Types): Categorical embedding for 10 room categories (Living Room, Bedroom, Bathroom, Kitchen, Balcony, Corridor, Dining Room, Storage, Study, Other).
  * Node Target Areas: Continuous feature vector f_area = [ sqrt(A_target)/S, log(A_target)/10.0 ].
  * Graph Adjacency: Relational adjacency matrix A in {0, 1, 2, 3}^{N x N}.
  * Global Envelope Token: Exterior building boundary bounding box coordinates [x_min, y_min, x_max, y_max] and aspect ratio W/H.

5. DIFFUSION PROCESS & SAMPLING SETUP
--------------------------------------------------------------------------------
- Timesteps: T = 1,000 steps during training.
- Noise Schedule: Cosine noise schedule (squared cosine formulation beta_t = 1 - alpha_bar_t / alpha_bar_{t-1}, s = 0.008) preventing abrupt SNR collapse at t -> T.
- Prediction Target: Clean coordinates parameterization (x_0-prediction, where the neural network directly predicts x_0_hat instead of epsilon_t).
- Sampler at Inference: Deterministic DDIM (Denoising Diffusion Implicit Models) sampler.
- Inference Sampling Steps: 50 steps (uniform sub-sequence tau from 1,000 down to 0, eta = 0.0).

6. OBJECTIVE FUNCTION & LOSS BALANCING
--------------------------------------------------------------------------------
The loss function balances coordinate reconstruction with soft architectural regularizers:
  L_total = L_recon + w_ortho * L_ortho + w_area * L_area + w_overlap * L_overlap + w_bound * L_bound

Loss Terms and Weights for Best Run:
- L_recon (Base Coordinate Loss): Mean Squared Error ||x_0_hat - x_0||^2 (Weight = 1.0).
- L_ortho (Orthogonality Penalty): Soft penalty on non-perpendicular adjacent edge vectors:
  L_ortho = mean( |dot(e_i, e_{i+1}) / (||e_i|| * ||e_{i+1}|| + eps)| ) (Weight w_ortho = 0.5).
- L_area (Target Area Fidelity): Smooth L1 loss between predicted room polygon area and target area A_target (Weight w_area = 0.2).
- L_overlap (Soft Repulsion Penalty): Differentiable pairwise intersection penalty via smooth bounding approximations (Weight w_overlap = 0.1, warm-started after 10,000 steps).
- L_bound (Envelope Containment): Penalty for vertices extending beyond normalized boundary [-1.0, 1.0] (Weight w_bound = 0.2).

Comparison of Loss Weighting Across Ablations:
- Collapsed / Worst Run: w_overlap = 10.0, w_valid = 5.0 (without annealing or warm-up; gradient exploded).
- Medium Run: w_overlap = 0.0, w_valid = 0.0, w_area = 0.0 (unconstrained diffusion + post-hoc boolean difference).
- Best Run: w_overlap = 0.1 (warm-started), w_area = 0.2, w_ortho = 0.5, w_bound = 0.2.

8. INFERENCE AND POST-PROCESSING PIPELINE
--------------------------------------------------------------------------------
The key distinction between the Medium Run and Best Run lies in the post-processing pipeline:
- Problem with Medium Run: Boolean difference (p1.difference(p2)) destroys polygon area fidelity (reducing Area OK to 0.008%) and creates sliver polygons or degenerate fragments.
- Best Run Post-Processing Pipeline:
  1. Orthogonal Rectilinear Snapping:
     * Quantizes edge orientations to nearest 90-degree axes (0, 90, 180, 270 deg).
     * Standard bedrooms, bathrooms, and corridors snapped to 4-vertex axis-aligned bounding rectangles.
     * Living room fitted to V in {4, 6, 8} vertices (supporting L-shape, T-shape, or rectangle geometries).
  2. Contact-Preserving Minimum Translation Vector (MTV) Relaxation:
     * Instead of subtracting intersecting regions, MTV computes the separating axis and penetration depth between overlapping polygons.
     * Iteratively applies elastic translation vectors to push overlapping rooms apart until non-overlapping.
     * Preserves room area and shared wall contacts necessary for graph connectivity edges.
  3. Boundary Snapping & Active Envelope Fit:
     * Clamps room boundaries to the building exterior envelope (tolerance tau = 2.0 canvas units).
     * Enforces minimum room area threshold A_min >= 20.0 m^2.

9. METRIC DEFINITIONS & EVALUATION PROTOCOL
--------------------------------------------------------------------------------
- Compatibility Success Rate (CSR Top-1):
  Fraction of floorplans where the top-ranked candidate satisfies:
  (1) All required room categories present and valid.
  (2) 100% geometric polygon validity (non-self-intersecting, positive area).
  (3) 0% room overlap violations (overlap area == 0).
  (4) All rooms meet Area OK criterion (|A_gen - A_target| / A_target <= 30%).
  (5) Complete recall of bubble graph adjacency edges.
- Strict CSR (Top-1 Strict):
  Adds strict building exterior containment (no room leaking outside perimeter) and zero spurious graph edges.
- CSR Any-of-K (K=16):
  Floorplan is deemed successful if at least one candidate among the 16 generated samples meets the CSR criteria.
- CSR Mean-over-K:
  The unconditional expectation of CSR across all 16 * 1,560 = 24,960 generated floorplan samples.
- Topology Consistency:
  Exact graph isomorphism between the generated room contact graph and the input bubble graph (Recall = 100% and Spurious Rate = 0%).
- Area-OK Tolerance:
  Relative area deviation |A_gen - A_target| / A_target <= 0.30 (30% tolerance).
- Canvas Units & Real-World Dimensions:
  Canvas is 256 x 256 units. The canonical real-world bounding dimension is 25.6 m x 25.6 m.
  Therefore, 1 canvas unit = 0.10 meters (10 cm). A centroid error of 57.76 units corresponds to ~5.78 meters.
- Room IoU:
  Intersection-over-Union between generated room polygon and ground truth room polygon matched via Hungarian bipartite matching.
- Vertex-Count Accuracy:
  Fraction of rooms where len(vertices_gen) == len(vertices_GT).
- Top-1 Selection Protocol:
  From K = 16 generated candidates, Top-1 is ranked using composite quality score:
    Score = Validity * (1 - Overlap_Viol) * exp(-Area_Err) * Connectivity_Recall
- Test Split (1,560 vs 1,632 plans):
  The initial test pool contained 1,632 plans. A strict graph deduplication filter using bubble graph structural Jaccard similarity (threshold r = 0.004) identified 68 near-duplicate plans that had significant graph isomorphism overlap with training split entries. These 68 plans were pruned to guarantee zero test leakage, resulting in exactly 1,560 test floorplans.

10. DEVIATIONS FROM CHAT-HOUSE-DIFFUSION & PRIOR WORK
--------------------------------------------------------------------------------
- Denoising Space: ChatHouseDiffusion relies on autoregressive discrete sequence tokens for room corner sequences. Our method uses continuous 2D coordinate diffusion via a Diffusion Transformer (DiT).
- Graph Conditioning: Upgraded from flat GCN message passing to a 4-layer Graphormer with relational edge attention biases.
- Post-Processing: Replaced destructive CSG boolean difference clipping with Contact-Preserving MTV relaxation, preventing area collapse (recovering Area OK from 0.008% to 96.47%).
- Living Room Morphological Regularization: Enforces living room vertex count V in {4, 6, 8} rather than allowing unconstrained irregular polygonal artifacts.
