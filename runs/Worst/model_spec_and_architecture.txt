================================================================================
EXPERIMENT RUN SPECIFICATION: WORST RUN (COLLAPSED LOSS EXPLOSION)
================================================================================

1. RUN IDENTIFICATION & MAPPING
--------------------------------------------------------------------------------
- Designation: Run 1 (Worst / Collapsed Run)
- Evaluation File: runs/Worst/eval_metrics.json
- Evaluated Plans: 1,560 held-out test floorplans (K=16 samples per graph, 50 steps)
- Key Characteristic: Catastrophic geometric collapse caused by unnormalized auxiliary loss explosion.
  * Invalid Polygons: 65.05% (worst recorded rate across all experiments)
  * Spurious Edge Touches: 74.46% (runaway accidental room contacts)
  * Area Matching Rate: 5.39% (rooms severely shrunken/distorted)
  * Overlap Violation Rate: 100.0% (every generated layout had overlapping rooms)
  * Constraint Satisfaction Rate (CSR Top-1): 0.00%
- Companion Baseline Reference: The earlier unconstrained baseline (Phase 2) had 44.13% invalid polygons,
  92.04% connectivity, and 97.31% overlap violations.

2. MODEL ARCHITECTURE
--------------------------------------------------------------------------------
- Architecture Type: Dual-Transformer Architecture (Graphormer + Diffusion Transformer)
  * Conditioning Encoder: Graph Transformer (relational graph attention over bubble graph)
  * Generative Denoiser: Conditional Vertex/Polygon Transformer (AdaLN-modulated cross-attention)
- Prediction Target: Direct clean coordinate prediction (x0-prediction) in centered canvas units.
- Model Dimensions:
  * Hidden Size (d_model): 256
  * Attention Heads (n_heads): 8 (head dimension dk = 32)
  * Graph Encoder Layers: 4 GraphBlock layers with learnable relational edge-type bias
  * Denoiser Layers: 6 DenoiseBlock layers (Self-Attention + Cross-Attention + MLP)
  * MLP Expansion: 4x (hidden size 1024 with GELU activation)
  * Dropout: 0.1
  * Total Parameter Count: 13,374,210 (~13.37M parameters)
- What the Model Generates: Ordered 2D vertex coordinates [B, N, K, 2] on a 256x256 canvas
  normalized by dataset-wide train scale constant S = 168.0.

3. CONDITIONING INPUT & ENCODING
--------------------------------------------------------------------------------
- Input Graph G = (V, E):
  * Room Categories (V): 8 architectural types (living, bedroom, bathroom, kitchen, door,
    window, wall, front_door), encoded via nn.Embedding(NUM_ROOM_TYPES, d_model).
  * Target Room Areas (A): Requested square footage encoded via a 2D continuous vector:
    [sqrt(A)/S, log(A)/10.0] mapped through a linear projection layer.
  * Adjacency Edges (E): 4 connection types (none, direct, via_door, via_window), injected as
    a learnable attention bias tensor in the Graph Transformer: attn_bias[u, v] in R^{heads}.
  * Global Token: A learnable layout-level summary token appended to the node sequence.
- Ground-Truth Coordinates: NEVER fed into the conditioning encoder (strictly preserved as
  pure graph conditioning).

4. DIFFUSION SETUP
--------------------------------------------------------------------------------
- Timesteps (T): 1,000 discrete diffusion steps.
- Noise Schedule: Cosine schedule for alpha_bar_t (Nichol & Dhariwal, 2021).
- Diffusion Target: Clean layout x0-prediction objective:
    L_diff = || x0_hat - x0 ||^2 * token_mask
- Sampler: DDIM deterministic sampler (eta = 0.0).
- Sampling Trajectory: 50 inference timesteps linearly spaced from T-1 down to 0.

5. LOSS FUNCTIONS & EXACT WEIGHTS (THE CAUSE OF COLLAPSE)
--------------------------------------------------------------------------------
- Base Diffusion Loss: Coordinate MSE (weight = 1.0).
- Auxiliary Geometric Losses (Phase 3):
  * --w_overlap: 10.0 (Unreasonably aggressive pairwise soft-rasterized overlap penalty)
  * --w_valid: 5.0 (Unnormalized self-intersection edge cross-product penalty)
  * --w_area: 1.0 (Shoelace formula smooth L1 area ratio penalty)
  * --w_conn: 2.0 (Relational pairwise contact distance penalty)
  * --w_nonconn: 1.0 (Non-edge separation margin penalty)
  * --w_ortho: 0.0 (Not enabled in this run)
  * --w_aspect: 0.0 (Not enabled in this run)
- Root Cause of Failure:
  In this run, validity_loss had raw edge cross products (len_i * len_j ~ 10,000) without
  normalization by target_area. Multiplied by w_valid = 5.0, validity loss gradients were
  ~50,000x larger than the diffusion coordinate gradients. The network panicked to minimize
  the gigantic penalty, contorting polygon vertices into chaotic self-tangled knots.

6. TRAINING SETUP
--------------------------------------------------------------------------------
- Optimizer: AdamW (lr = 2e-4, weight_decay = 0.01, betas = (0.9, 0.999)).
- Warmup: 1,000 linear warmup steps followed by cosine annealing.
- Batch Size: 32 layouts per batch.
- Gradient Clipping: 1.0 max norm.
- Exponential Moving Average (EMA): Decay rate = 0.999.
- Total Epochs: 200 epochs.
- Split Details: 13,023 train plans, 1,562 validation plans, 1,560 test plans.
- Hardware: NVIDIA RTX 3080 GPU (TF32 precision enabled).

7. INFERENCE & POST-PROCESSING
--------------------------------------------------------------------------------
- Sampling: Raw DDIM 50-step sampling with no post-processing collision separation.
- Guidance: Unconstrained inference guidance attempt (--guidance 1.0) which tangled vertices.
- Polygon Construction: Direct Shapely Polygon conversion from raw unconstrained coordinates.

8. EVALUATION PROTOCOL & METRIC DEFINITIONS
--------------------------------------------------------------------------------
- Test Dataset Size: 1,560 plans (out of 1,632 raw test splits).
  * Explanation: 68 near-duplicate layouts were filtered from the evaluation split using
    cKDTree L-infinity invariant area/edge descriptors (radius = 0.004) to prevent data
    leakage and train/test contamination (strict compliance with ResPlan Rules 26/27).
- Multi-Sample Generation: K = 16 independent layouts drawn per test graph.
- Top-1 Selection: Ranked by Candidate score:
    score = 1.0 * area_err + 3.0 * overlap_sum + 2.0 * topology_err + 10.0 * n_invalid
  (Candidates passing all validity constraints are strictly prioritized).
- Metric Definitions:
  * CSR (Constraint Satisfaction Rate): Percentage of layouts passing ALL constraints
    (valid polygons, zero overlap, area within 30%, all required edges connected).
  * Strict CSR: Layouts satisfying CSR with zero spurious edge touches.
  * Area OK: All rooms within 30% relative error: |A_pred - A_req| / A_req <= 0.30.
  * Centroid & Coordinate Error: Euclidean distance in 256-unit canvas space (S = 168.0).
  * IoU: Intersection over Union with ground truth after centroid alignment.
